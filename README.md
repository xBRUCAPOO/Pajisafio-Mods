# COMO PONER LOS MODS
> Si se está en TLauncher
1. [Descargar el .ZIP](https://github.com/xBRUCAPOO/Pajisafio-Mods/archive/refs/heads/main.zip)
2. Abrir TLauncher
3. Presionar sobre el icono de la carpeta abajo de la derecha
4. Abrir la carpeta "mods"
5. Poner el .ZIP ahí dentro
6. Descomprimir aquí
7. Elimina el .ZIP

El .ZIP debería de estar en el directorio
```js
%appdata%\.minecraft\mods
```
